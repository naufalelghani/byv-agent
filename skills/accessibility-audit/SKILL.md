# Accessibility Audit

Use this skill when implementing or reviewing user-facing UI, especially interactive flows.

## Workflow
1. Inspect project accessibility standards and the relevant user journeys/components.
2. Check semantic structure, heading order, labels and accessible names, keyboard access, focus order/visibility, and interaction states.
3. Evaluate color contrast, non-color cues, zoom/reflow, responsive behavior, reduced motion, and error/status announcements as applicable.
4. Use automated checks as a supplement, not a substitute for keyboard and manual review.
5. Record reproducible issues with affected element/flow, impact, evidence, and a practical fix.

## Output
Report findings by severity and user impact, note tested scope and tools, and distinguish automated results from manual checks. Do not claim WCAG conformance based on a partial audit.
